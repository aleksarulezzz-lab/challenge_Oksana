# «Перепридумай себя» · сайт-календарь челленджа Оксаны Миковой

21 день, 3–23 ноября 2026. Статичный сайт без сборки: HTML, CSS и ES-модули.

## Что внутри

- **Первый экран**: 3D-компас в ретро-стиле (Three.js). При прокрутке он разлетается на 21 деталь: корпус, платина, шестерёнки, пружины, винты, рубин, циферблат, стрелка, стекло, безель, головка.
- **Календарь**: 21 карточка (3 недели по 7). Задание дня открывается в 06:00 МСК, будущие дни закрыты. Состояния: сегодня, выполнено, частично, пропущено, закрыто.
- **Карточка дня**: два задания Оксаны и третье задание «отчёт в соцсетях» с хэштегом и заготовкой текста, кнопки «Сделала» / «Пропускаю», личный шаг, заметки. День засчитывается, когда отмечены все три задания (настройка `tasksToCountDay`). Отметки можно менять до 24 ноября 23:59 МСК.
- **Прогресс**: кольцо засчитанных дней, счётчики, маршрут-бегунок из 21 точки и список пропущенных дней.
- **Моя цель**: цель, зачем, награда, шаги, кнопка «Скачать мою цель».
- **Итоговая карта**: картинка 1080×1920 для сторис (скачать / поделиться), цель только по галочке.
- **«Удалить мои данные»** в подвале.

## Где менять содержание

Всё в `js/data.js`: название, даты, хэштег, правило засчитывания дня, награда, темы и тексты 21 дня.

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Проверка без ожидания 3 ноября:

- `?date=2026-11-10` — открыть сайт так, будто сегодня 10 ноября;
- `?demo` — ползунок внизу экрана, чтобы «прожить» все 21 день;
- `#day-5` — сразу открыть карточку дня 5 (так можно давать ссылку из бота).

## Данные участниц

Сайт ничего не собирает и не отправляет (152-ФЗ): отметки, цель и шаги хранятся только в браузере участницы (`localStorage`, `js/store.js`). Подтверждение прохождения: участница отправляет Оксане в Telegram свою «Карту 21 дня» с именем. Подробнее в `HANDOFF.md`.

Three.js (MIT) лежит в `vendor/`.
