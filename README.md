# «Перепридумай себя» · сайт-календарь челленджа Оксаны Миковой

21 день, 3–23 ноября 2026. Статичный сайт без сборки: HTML, CSS и ES-модули.

## Что внутри

- **Первый экран**: 3D-компас в ретро-стиле (Three.js). При прокрутке он разлетается на 21 деталь: корпус, платина, шестерёнки, пружины, винты, рубин, циферблат, стрелка, стекло, безель, головка.
- **Календарь**: 21 окно (3 недели по 7). Окно дня открывается в 06:00 МСК, будущие окна закрыты. Состояния: сегодня, выполнено, частично, можно вернуться, пропущено, закрыто. ★ якорные дни.
- **Окно дня**: два задания Оксаны с кнопками «Сделала» / «Пропускаю», заготовка для отчёта в соцсетях, личный шаг, заметки. Отметки можно менять до 24 ноября 23:59 МСК.
- **Прогресс**: кольцо засчитанных дней, счётчики, маршрут-бегунок из 21 точки и список «Можно нагнать».
- **Моя цель**: цель, зачем, награда, шаги, кнопка «Скачать мою цель».
- **Итоговая карта**: картинка 1080×1920 для сторис (скачать / поделиться), цель только по галочке.
- **«Удалить мои данные»** в подвале.

## Где менять содержание

Всё в `js/data.js`: название, даты, правило засчитывания дня, награда, темы и тексты 21 дня.

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Проверка без ожидания 3 ноября:

- `?date=2026-11-10` — открыть сайт так, будто сегодня 10 ноября;
- `?demo` — ползунок внизу экрана, чтобы «прожить» все 21 день;
- `#day-5` — сразу открыть окно дня 5 (так можно давать ссылку из бота).

## Ограничения первой версии

Сейчас отметки хранятся в браузере участницы (`localStorage`, файл `js/store.js`). Чего пока нет из ТЗ: сервер, вход по личной ссылке из бота, синхронизация отметок с ботом, кабинет Оксаны со сводкой и выгрузкой CSV, серверная проверка даты окна. Для этого нужен бэкенд; `js/store.js` — единственное место, которое придётся подключить к API.

Three.js (MIT) лежит в `vendor/`.
