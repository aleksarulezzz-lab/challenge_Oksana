```
index.html        разметка всех разделов

                  шрифты Playfair Display, Inter, Bodoni Moda)

js/app.js         логика страницы
js/compass.js     3D-компас (Three.js 0.170, RoomEnvironment)
js/store.js       хранение в localStorage (ключ challenge21:v1)
assets/           favicon, топографический фон, SVG-заглушка компаса
vendor/           three.module.min.js, RoomEnvironment.js, лицензия
.nojekyll         чтобы GitHub Pages отдавал файлы как есть
```

## Как запустить

```bash
python3 -m http.server 8000
```

Открыть http://localhost:8000. Параметры для проверки:
- `?date=YYYY-MM-DD` — представить, что сегодня эта дата;
- `?demo` — ползунок внизу, чтобы пройти все 21 день;
- `#day-N` — сразу открыть карточку дня N.

Публикация: GitHub Pages, Settings → Pages → Deploy from a branch → ветка, папка `/ (root)`.
Ссылка: https://aleksarulezzz-lab.github.io/challenge_Oksana/ (для превью добавлять `?demo`).

## Принятые решения

- **Никакого сбора данных (152-ФЗ).** Оксана не зарегистрирована в Роскомнадзоре как оператор ПД. Поэтому нет форм, сервера, аналитики, бота и push-рассылок. Отметки, цель и шаги хранятся только в браузере участницы. Google Формы и зарубежные сервисы не подходят из-за требования локализации.
- **Как Оксана узнаёт, кто прошёл всё.** Участница собирает «Карту 21 дня» со своим именем и отправляет её Оксане в Telegram (t.me/OksanaMikova). Награда: месяц в клубе, 3 000 ₽. Карту можно подделать, это принятый риск; отчёты под хэштегом служат проверкой.
- **Напоминание** — файл .ics с ежедневным событием в 12:00 МСК, участница сама добавляет его в календарь телефона.
- **Логика дней.** День открывается в 06:00 МСК. В дне 3 задания: 2 от Оксаны + отчёт в соцсетях с хэштегом `#челленджОксаныМиковой`. День засчитан при 3 из 3. Статусы: сегодня, выполнено, частично, пропущено; прошедшие незавершённые дни помечены бордовым «Нужно вернуться». Догнать можно до 24.11 23:59 МСК.
- **Эфиры**: 8, 15 и 22 ноября, около 40 минут, время Оксана объявит сама.
- **Компас**: процедурная модель из 21 детали; при скролле разлетается и выстраивается в маршрут из 21 точки; стрелка следует за курсором или наклоном телефона.
- **Анимации** появления блоков привязаны к скроллу, по очереди, без мерцания текста.
- **Тексты** (правки Уильяма): без «можно по минимуму», «окон», «якорных дней», безличного «мы» и намёков на продажи. Оксана говорит от первого лица, участницам — на «вы».
